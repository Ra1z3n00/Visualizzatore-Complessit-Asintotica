# 📊 Visualizzatore Complessità Asintotica

Un'applicazione web interattiva progettata per visualizzare e confrontare il comportamento asintostico degli algoritmi nei tre scenari fondamentali: **Caso Peggiore ($O$)**, **Caso Migliore ($\Omega$)** e **Caso Medio ($\Theta$)**.

## 🚀 Funzionalità
* **Selezione Algoritmi:** Confronto tra Quick Sort, Merge Sort, Insertion Sort, Ricerca Binaria, Fibonacci Ricorsivo e altri.
* **Grafici Dinamici:** Rendering in tempo reale delle curve di crescita al variare dell'input $N$ tramite Chart.js.
* **Spiegazione dei Casi:** Mappatura precisa tra la notazione matematica e lo scenario d'input reale.
* **Interfaccia Responsiva:** Layout pulito con tabella riassuntiva dei valori stimati.

## 🛠️ Tecnologie Utilizzate
* HTML5 / CSS3
* JavaScript (ES6)
* [Chart.js](https://www.chartjs.org/)
